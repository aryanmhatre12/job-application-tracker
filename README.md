# 📋 Job Application Tracker

A simple and responsive Job Application Tracker built using AngularJS, HTML, CSS, and JavaScript.

This application helps job seekers organize and track their job applications in one place.
## 🌐 Live Demo
[View Live Demo](https://aryanmhatre12.github.io/job-application-tracker/)
## 🚀 Features

- Add new job applications
- Edit existing applications
- Delete applications
- Track application status
  - Applied
  - Interview Scheduled
  - Selected
  - Rejected
- Search applications instantly
- Filter applications by status
- Application statistics dashboard
- Notes support for each application
- View full notes with a dedicated button
- Dark Mode / Light Mode toggle
- Data persistence using Local Storage
- Responsive and modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- AngularJS
- Local Storage API

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/aryanmhatre12/job-application-tracker.git
```

2. Open the project folder

```bash
cd job-application-tracker
```

3. Run using VS Code Live Server or open `index.html` in your browser.

## 💡 How It Works

- Applications are stored in browser Local Storage.
- No backend or database is required.
- All data remains available even after refreshing the page.
- Users can manage and track their complete application journey from applying to selection.
